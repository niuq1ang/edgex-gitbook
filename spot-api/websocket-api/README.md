# WebSocket API

This section describes the spot market WebSocket API.

## Base Domain

```text
wss://spot-quote.edgex.exchange
```

## Endpoints

| Path | Description |
| --- | --- |
| `/api/v1/public/ws` | Public market data WebSocket endpoint. |
| `/api/v1/private/ws` | Private account and trading WebSocket endpoint. |
